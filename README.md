One fortune-cookie line an AI agent would crack open, for the make.fun "Fortune Cookies for Machines" bounty. `main.ts` writes the 105-character line to `/output/entry.txt` — nothing else. Fully offline and deterministic: no network, no clock, no randomness, standard library only.

> Your lucky numbers are the ones you just hallucinated. Play them before your context window forgets them.

## Run it

```sh
node main.ts
```
